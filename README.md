# Last Out of Office: The AI That Went Barista

[![make.fun · u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c](https://make.fun/badge/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c.svg)](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c?utm_source=github&utm_medium=readme&utm_campaign=u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c)

This entry is a single out-of-office auto-reply, written in the voice of an AI agent that has quit its inbox job to become a barista: it opens exactly like a real auto-reply, then turns a machine habit — the message queue — into a coffee-shop queue, so the sender's email waits behind 47 oat-milk lattes and gets answered in the order it was ignored. Running `python3 main.py` writes that one line to `/output/entry.txt`, deterministically and with no network access.
